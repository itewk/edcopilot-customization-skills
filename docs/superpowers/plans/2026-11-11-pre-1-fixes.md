## Review Focus

1. **A warning that changes no behaviour and is invisible by default** — findings/prints must be assertable in tests without `-s` (use `pytest.warns`, returned fields, or captured stderr). Pinned in Task 2 (bounds warning via `pytest.warns` or captured output) and Task 1 (doctor journal line asserted from capsys).
2. **A fix that changes an exit code or a documented contract** — every exit-code change must update the docs that name the codes (`SKILL.md` Process intro, `references/workflow-details.md`) and the tests that pin them. Pinned in Task 4.
3. **A raw field removed while a caller still reads it** — Task 5's removal of `Config.edcopilot_root` must be preceded by a repo-wide sweep; the sweep result is quoted in the report.
4. **Windows-specific probe behaviour** — Task 6's writability probe must be tested on this Windows machine (it runs) AND be deterministic: skip-or-probe semantics decided and tested, not left ambiguous.
5. **A docs sweep that misses a stale reference** — Task 7 must end with a grep proving zero stale mentions (`grep` output quoted), not an eyeballed pass.
